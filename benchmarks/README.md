# Pruebas de rendimiento / Performance tests

## Español

La infraestructura F3-001 proporciona un *smoke test* reproducible que compara implementaciones y detecta fallos básicos. Sus tres muestras por combinación no permiten extraer clasificaciones ni conclusiones de velocidad. El análisis estadístico y las métricas aisladas están pendientes.

Para ejecutar un *smoke*, consulta `benchmarks/run.php` y `benchmarks/config.php`; la salida debe dirigirse a un archivo dentro de `resultados/` (ignorado por Git).

---

## English

The F3-001 infrastructure provides a reproducible smoke test for basic implementation comparisons and failures. Three samples per combination are insufficient for performance rankings or speed claims. Statistical analysis and isolated metrics remain pending.

To run the smoke test, see `benchmarks/run.php` and `benchmarks/config.php`; write generated output under `resultados/` (ignored by Git).
