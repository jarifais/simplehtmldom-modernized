# PKG-002 — Registro y verificación en Packagist / Packagist registration and verification

## Español

### Objetivo

Registrar públicamente el paquete Composer **`jarifais/simplehtmldom-modernized`** con el repositorio existente, sin modificar el parser, las funciones globales, la licencia MIT ni la etiqueta de la primera beta. Esta subfase se considera **pendiente** mientras Packagist no confirme el registro y los dos runners no superen la instalación desde su índice público.

**Repositorio a registrar:** https://github.com/jarifais/simplehtmldom-modernized

**Nombre declarado en `composer.json`:** `jarifais/simplehtmldom-modernized`.

**Versión que debe aparecer:** `v0.1.0-beta.1` (normalizada por Composer como `0.1.0-beta.1`).

**Commit inmutable de esa versión:** `1047dd573014913a42f58aad343ce453d8d66f3a`.

### Registro inicial (acción del propietario autenticado)

1. Accede a https://packagist.org/ e inicia sesión con GitHub o crea/vincula tu cuenta de Packagist. No compartas contraseñas ni tokens en el chat, repositorio o logs.
2. En https://packagist.org/packages/submit introduce **exactamente** `https://github.com/jarifais/simplehtmldom-modernized` como URL de repositorio y confirma el registro. Comprueba que el nombre identificado es `jarifais/simplehtmldom-modernized`; no publiques bajo otro vendor.
3. Autoriza la integración GitHub ↔ Packagist para permitir la actualización automática del repositorio, siguiendo el proceso de Packagist. Evita introducir un token personal como texto en ficheros, comandos visibles o parámetros de URL. Si Packagist no consigue activar la sincronización automática, consulta https://packagist.org/about y revisa las autorizaciones de la aplicación Packagist en GitHub.
4. Comprueba que https://packagist.org/packages/jarifais/simplehtmldom-modernized presenta la versión `v0.1.0-beta.1` y apunta al commit anterior. Si no aparece, espera a que termine el análisis inicial; no cambies la etiqueta Git.
5. En https://github.com/jarifais/simplehtmldom-modernized/actions/workflows/packagist.yml selecciona **Run workflow** sobre `main`. Exige PASS tanto para `ubuntu-24.04` como para `windows-2025`.
6. Solo tras los dos PASS se podrá declarar completada PKG-002 y simplificar las instrucciones de instalación en el README. Los consumidores podrán instalar explícitamente la beta con `composer require 'jarifais/simplehtmldom-modernized:0.1.0-beta.1'`, sin añadir ningún repositorio VCS adicional.

### Verificación automática añadida

- El workflow `.github/workflows/packagist.yml` es manual para la prueba real. Durante una pull request ejecuta **solo un preflight de sintaxis y hashes**; nunca registra ni publica paquetes.
- El script `distribucion/verificar_packagist.ps1` es un bloque PowerShell `& { }` y utiliza únicamente endpoints públicos, PHP 8.4 y Composer; no necesita ningún token de Packagist.
- Consulta el índice público de Packagist y exige que la versión beta resuelva el commit `1047dd...`. Crea un consumidor Composer temporal **sin propiedad `repositories`**, instala el paquete desde Packagist.org y verifica el `composer.lock`, la licencia, el SHA-256 de las dos rutas del PHP, lint y funciones/clases clásicas en un proceso PHP nuevo.
- Borra el consumidor temporal y restaura el entorno Composer; si falta la versión, los hashes no coinciden o hay fallos de red/instalación, **aborta sin declarar PASS**.
- La batería de compatibilidad continúa limitada a PHP 8.4 en Windows y Ubuntu; no se certifican otras versiones con esta prueba.

### Seguridad y alcance

Packagist.org es el repositorio público, distinto de Private Packagist. No es necesario instalar un plugin de Composer ni entregar credenciales a GitHub Actions para esta verificación. La sincronización automática puede realizarse mediante la integración OAuth/GitHub App propuesta por Packagist. Esta subfase **no modifica** `librerias/original`, `librerias/fase1`, `simple_html_dom.php`, ni la API pública, ni la versión beta ya publicada. Los futuros cambios del parser requieren subfases propias.

## English

### Goal

Register the already released Composer library **`jarifais/simplehtmldom-modernized`** on public Packagist.org without changing the parser, global public API, MIT license, or existing beta tag. PKG-002 remains **pending** until Packagist indexes the package and both operating-system runners confirm a direct install from the public index.

**Source repository:** https://github.com/jarifais/simplehtmldom-modernized

**Declared package name:** `jarifais/simplehtmldom-modernized`.

**Required indexed prerelease:** `v0.1.0-beta.1` (Composer version `0.1.0-beta.1`).

**Immutable tag commit:** `1047dd573014913a42f58aad343ce453d8d66f3a`.

### First submission (authenticated owner action)

1. Sign in to https://packagist.org/ with GitHub or link/register your Packagist account. Do not send credentials or API tokens in chat.
2. Open https://packagist.org/packages/submit and submit **exactly** `https://github.com/jarifais/simplehtmldom-modernized`. Confirm that the detected package name is `jarifais/simplehtmldom-modernized`.
3. Enable the official GitHub-to-Packagist synchronization using Packagist's authentication/integration flow. Do not put secrets in repository files or readable commands; consult https://packagist.org/about if the integration cannot be enabled automatically.
4. Confirm https://packagist.org/packages/jarifais/simplehtmldom-modernized lists the `v0.1.0-beta.1` prerelease on the expected source commit. Allow the initial crawler to finish; never move the already-published tag.
5. Open https://github.com/jarifais/simplehtmldom-modernized/actions/workflows/packagist.yml and **Run workflow** on `main`. Require green Ubuntu 24.04 and Windows 2025 verification jobs.
6. After these jobs pass, PKG-002 can be closed and the README updated to advertise direct installation with `composer require 'jarifais/simplehtmldom-modernized:0.1.0-beta.1'` without a VCS repository entry.

### Automated verification and safeguards

The pull-request workflow only checks PowerShell syntax and source hashes. A separate manual workflow invokes `distribucion/verificar_packagist.ps1` on PHP 8.4 under Windows and Ubuntu. This script does **not** require a Packagist token; it reads public package metadata and builds an isolated Composer consumer **without a VCS repository override**. It asserts the exact beta tag commit, version, lockfile, parser SHA-256, MIT license, PHP lint and original global API. Temporary directories and Composer environment variables are restored, and no PASS is claimed upon failure.

Only PHP 8.4 has been tested on both operating systems. No library implementation, original reference, public API, or release assets change in PKG-002.
