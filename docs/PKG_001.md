# PKG-001 — Paquete Composer / Composer package

## Español

### Alcance

Esta subfase habilita la instalación como dependencia Composer **sin alterar el código del parser ni la API pública de Simple HTML DOM 1.9.1**. No constituye un registro en Packagist, ni crea una release o un tag estable.

Se actualiza `composer.json`:
- Paquete: `jarifais/simplehtmldom-modernized`, `type: library`, licencia MIT.
- Requisitos declarados de ejecución: `php >=8.2`, `ext-iconv`; `ext-mbstring` es una sugerencia opcional.
- `autoload.files`: `librerias/fase1/simple_html_dom.php`. Esta fuente y `simple_html_dom.php` son idénticas (checkpoint SHA-256 `bba1d651b7c58eab6e70a031a6d8ca52b86c68bc746188440652f877b9110d25`). Se mantiene esta ruta para que las pruebas PHPUnit heredadas puedan utilizar `require_once` sobre el mismo archivo sin volver a declarar las funciones globales.
- `phpunit/phpunit` se conserva únicamente en `require-dev` (no se instala en los proyectos consumidores).
- `composer.lock` heredado, creado para un proyecto de pruebas distinto, se retira de Git y se ignora. La biblioteca no fija dependencias transitivas de sus consumidores; **los proyectos consumidores sí deben versionar su propio `composer.lock`** si usan Composer.
- Se preserva el script de pruebas `composer test` como herramienta de desarrollo, que requiere el entorno local de pruebas preparado.

### Verificación añadida

`distribucion/validar_composer.ps1`, encapsulado en `& { }`, construye un consumidor temporal con un repositorio Composer de tipo `path` (copia física, no symlink), instala la dependencia, comprueba los SHA-256 de original, fase1, archivo único y licencia, y ejecuta `vendor/autoload.php` en un proceso PHP aislado. Verifica funciones/clases tradicionales y los métodos `hasAttribute()`/`removeAttribute()`.

Una nueva matriz en GitHub Actions repite esta verificación en Ubuntu 24.04 y Windows 2025, PHP 8.4. No cambia las pruebas existentes; los workflows de CI y ZIP permanecen activos.

### Instalación desde GitHub después de fusionar PKG-001

Hasta que haya versiones etiquetadas y registro en Packagist, en un proyecto PHP compatible:

```sh
composer config repositories.simplehtmldom-modernized vcs https://github.com/jarifais/simplehtmldom-modernized
composer require jarifais/simplehtmldom-modernized:dev-main
```

```php
<?php
require_once __DIR__ . '/vendor/autoload.php';
$html = str_get_html('<h1>Hola Composer</h1>');
echo $html->find('h1', 0)->plaintext;
$html->clear();
```

No mezclar con otra versión de Simple HTML DOM que defina las mismas funciones/clases globales. La rama `dev-main` es **inestable**: conviene fijar una revisión concreta en proyectos de producción. Las compatibilidades distintas a PHP 8.4 permanecen pendientes de pruebas, aunque el requisito declarado permita PHP 8.2 o superior.

### Criterios de aceptación

- GitHub CI completo y workflow ZIP sin regresiones.
- Matriz de consumidores Composer en Ubuntu y Windows: PASS.
- `composer validate --strict`: PASS.
- Instalar desde carpeta temporal aislada, cargar con Composer y ejercitar la API: PASS.
- Original, fuente corregida, archivo único y licencias: idénticos a sus checkpoints.
- No tocar librerías ni código ajeno ni fusionar si hay fallos.

## English

### Scope

PKG-001 turns this repository into a Composer **library**, without changing the parser or the upstream-compatible public API. It does **not** register a package on Packagist or issue a stable release/tag.

- Package: `jarifais/simplehtmldom-modernized`, MIT.
- Declared runtime: PHP `>=8.2`, required `ext-iconv`; `ext-mbstring` is suggested, not required.
- `autoload.files` loads the maintained `librerias/fase1/simple_html_dom.php`. This remains byte-for-byte identical to the standalone root file. Keeping this path also ensures existing PHPUnit `require_once` calls do not redeclare globally defined functions/classes.
- PHPUnit remains a **development-only** dependency.
- The obsolete test-project `composer.lock` is removed and ignored. Composer consumer **applications should commit their own lockfiles** for reproducible dependencies.
- Existing `composer test` remains a development helper and requires the local test environment.

### Automated tests

An `& { }`-wrapped PowerShell 7 script installs the package using an isolated temporary Composer `path` repository (without symlinks), verifies all relevant source hashes and MIT license, and tests the traditional global API via `vendor/autoload.php` in a fresh PHP process. GitHub Actions runs this check with PHP 8.4 on both Ubuntu and Windows, in addition to the existing CI and ZIP workflows.

### Development installation from GitHub

Before a Packagist listing or a tagged release exists:

```sh
composer config repositories.simplehtmldom-modernized vcs https://github.com/jarifais/simplehtmldom-modernized
composer require jarifais/simplehtmldom-modernized:dev-main
```

```php
<?php
require_once __DIR__ . '/vendor/autoload.php';
$html = str_get_html('<h1>Hello Composer</h1>');
echo $html->find('h1', 0)->plaintext;
$html->clear();
```

Do not mix this fork with other libraries that define the same global functions/classes. `dev-main` is an **unstable development branch**; pin a revision for production reproducibility. CI has verified PHP 8.4 only so far, even though the declared PHP constraint starts at 8.2.

### Acceptance

Full CI and ZIP workflows must remain green; both Composer consumer jobs and strict Composer validation must pass; installed package must work in a clean PHP process; parser and license checksums must remain unchanged. Never merge on unverified results.
