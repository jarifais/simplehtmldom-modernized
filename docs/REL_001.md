# REL-001 — Primera beta pública / First public prerelease

## Español

### Alcance y método de publicación

La subfase REL-001 prepara la primera entrega `v0.1.0-beta.1` de este fork no oficial de Simple HTML DOM 1.9.1. Es **una beta**, no una versión estable, y **no** implica registro en Packagist.

Únicamente se añaden automatización y documentación. `librerias/original/simple_html_dom.php`, `librerias/fase1/simple_html_dom.php`, `simple_html_dom.php`, licencia MIT, tests heredados y API pública permanecen inalterados.

La release se crea **solamente** al publicar la rama exacta `release/v0.1.0-beta.1` apuntando al commit HEAD validado de `main`. El script `releases/publicar_beta.sh` y el workflow `.github/workflows/release-beta.yml` exigen:

1. `main` debe apuntar exactamente a ese commit y la etiqueta/release no deben existir.
2. La ejecución completa más reciente de `CI` para dicho commit en `main` debe tener **4 jobs PASS** (funcionales, PHPUnit, Composer GitHub y limpieza en Windows/Ubuntu).
3. `Distribucion ZIP` debe tener **3 jobs PASS**, incluida la igualdad binaria entre Ubuntu y Windows.
4. Se descargan los dos ZIP temporales de dicha ejecución; se comparan byte a byte, verifican sus SHA-256 externos, el inventario cerrado de cinco archivos, el manifiesto interior, el lint y la ejecución de un ejemplo real tras extraer el paquete.
5. Los SHA-256 de bibliotecas original y corregida coinciden con los checkpoints y la copia de archivo único es idéntica a la fuente mantenida.
6. Se preparan seis assets: `simple_html_dom.php`, `simplehtmldom-modernized-v0.1.0-beta.1.zip`, `simplehtmldom-modernized-v0.1.0-beta.1.zip.sha256`, `SHA256SUMS_RELEASE.txt`, `LICENSE` y `NOTAS_v0.1.0-beta.1.md`.
7. La release se crea como **borrador**, se descargan de nuevo los seis assets y se compara su contenido contra los originales. Solo entonces pasa de borrador a **prerelease pública**. Si falla antes de publicarla, el script intenta eliminar el borrador y su etiqueta. Ningún proceso cambia `main`.
8. Después de publicar, se verifica que la release esté marcada como beta y su etiqueta apunte exactamente al commit autorizado.

### Compatibilidad y limitaciones

La dependencia Composer declara PHP >=8.2 con `ext-iconv`; los resultados automáticos realizados hasta ahora cubren **PHP 8.4** en Ubuntu 24.04 y Windows 2025. No se declara certificación multiversión. El parser no es un sanitizador HTML. Conserva licencia MIT y avisos del código original. Una release GitHub y el registro futuro en Packagist son hitos distintos.

En la PR se ejecuta únicamente `bash -n`, comprobación de checksum de fuentes y validación documental, **sin crear releases**. La rama de publicación se crea después de que CI y ZIP hayan terminado en verde sobre `main`.

Notas para usuarios: [`releases/NOTAS_v0.1.0-beta.1.md`](../releases/NOTAS_v0.1.0-beta.1.md).

## English

### Scope and release mechanism

REL-001 prepares the first **prerelease** `v0.1.0-beta.1` of this unofficial Simple HTML DOM 1.9.1 fork. It is not stable and does not constitute Packagist registration. Only distribution automation and bilingual documentation are added; the original and maintained libraries, standalone root PHP, MIT license, existing tests and public API remain unchanged.

A new `release/v0.1.0-beta.1` branch must point to the **exact current validated `main` commit**. The guarded workflow demands successful full CI (4 jobs) and ZIP distribution (3 jobs) for that SHA; identical Ubuntu and Windows archives; ZIP source, license, file inventory, internal/external hashes and standalone execution checks; and intact baseline SHA-256. It creates six immutable release assets, uploads them to a **draft** first, downloads them again to compare bytes, and only then publishes the prerelease. A failed draft is subject to cleanup; `main` is never changed.

Pull requests only run script syntax/source checks and **cannot publish a release**. The separate release branch is created after the successful post-merge CI and ZIP workflows have completed.

### Compatibility and caution

The Composer manifest declares PHP >=8.2 and `ext-iconv`; verified automated CI currently covers **PHP 8.4 only**, on Ubuntu 24.04 and Windows 2025. Other runtime versions remain uncertified. This parser is **not** an HTML sanitizer. The original MIT copyright notices are preserved. The eventual Packagist listing is a separate milestone.

User-facing notes: [`releases/NOTAS_v0.1.0-beta.1.md`](../releases/NOTAS_v0.1.0-beta.1.md).
